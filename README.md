# Usoar2024

## goals
The goal of this research project is to leverage a variety
of machine-learning techniques to:
* Transform Music Clips to fixed-length vector embedding
* Visualize Music Clips as Points in 2d Space
* Group Music into different categories based on the
vector embedding
* Create a recommendation based on a set of liked songs

## Potential Applications

lthough most of the applications would require a larger
modern dataset. some of the potential applications include:
* Music streaming services
* Automatically Cataloging Song
* Exploring the similarity of 2 songs
* Identifying shifts in music genres over time
